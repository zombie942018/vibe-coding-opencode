## 🔧 工具詳細說明

### 📚 隨機單字卡（`flashcard.html`）

**版本：** v1.1.0

**核心功能：**

- 內建 10 個常用英文單字，每個單字包含：英文、詞性、中文翻譯、英/中應用情境例句
- 卡片預設顯示英文，點擊卡片本體或「翻面」按鈕可切換中/英文（3D 翻轉動畫）
- 「下一題」按鈕隨機抽卡，採「洗牌 + 依序發牌」機制，確保一輪 10 題內不重複、也不會連續抽到同一張
- 進度顯示（第 X / 10 題），抽完一輪自動重新洗牌
- 鍵盤支援：空白鍵翻面、Enter 下一題
- 響應式設計，手機與電腦皆可使用

**操作方式：**

| 操作 | 方式 |
|---|---|
| 翻面 | 點擊卡片 或「翻面」按鈕（或按空白鍵） |
| 下一題 | 「下一題」按鈕（或按 Enter） |

**擴充單字：** 編輯檔案中 `const WORDS = [...]` 區塊，照格式新增物件即可（`en` / `pos` / `zh` / `exEn` / `exZh` 五個欄位）。

## 🗂 維護備忘（給未來的自己）

- **新增工具**：把單一 HTML 檔放進 repo → 更新「工具列表」表格 → 新增「工具詳細說明」區塊 → 在更新日誌加一筆 `v1.0.0`（工具級版本從 1.0.0 開始）。
- **修改既有工具**：工具內的變更直接寫進更新日誌，版本號按語意化版本規則遞增：
  - `vX.Y.Z`：Z = bug 修正；Y = 新增功能；X = 重大改版（介面或行為不兼容）。
- **推上 GitHub**：只要 commit 並 push，`README.md` 就會同步覆蓋遠端的舊版，不需要額外動作。
